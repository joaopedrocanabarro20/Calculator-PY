# Calculator-PY
Calculator project created in Python using the Tkinter GUI library. Gemini was used to assist in learning the library.

![Interface](images/interface.png)    ![ERRO](images/erro.png)    ![numbers](images/numbers.png)

## Features

The calculator supports basic mathematical operations through a graphical interface:

- Addition
- Subtraction
- Multiplication
- Division
- Decimal numbers
- Parentheses
- Clearing the display
- Error handling for invalid expressions

## Technologies

- Python 3
- Tkinter

Tkinter is used to create the graphical interface, including the calculator display, buttons and layout.
